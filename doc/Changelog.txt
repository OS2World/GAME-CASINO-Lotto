Lotto - Changelog
=================

1.10 (2026-10-06)
- Rewritten in C for Open Watcom 2.0 (wmake, wcc386, wlink, wrc, wipfc). The
  original was a VX-REXX program; its source code was recovered from the
  resource file Lotto.RES (kept in legacy/)
- License changed to GNU GPL v3 or later
- New project layout: src/, bin/, doc/, help/, legacy/
- Menus Game / Options / Help with the standard shortcuts: Ctrl+N Generate,
  Ctrl+L Clear, Ctrl+S Save to file, Ctrl+X Exit, Ctrl+F Frame Controls
- Six language user interface (English, Spanish, Dutch, German, French,
  Italian) and online help in six languages, switched at run time
- Standard About dialog
- Settings (language, numbers of the game, fixed numbers) are stored in
  Lotto.cfg
- Combinations are generated without repeating a number and listed in
  ascending order; the result file shows the numbers of the game
- A wrong entry no longer wipes the other fields

1.02 (1999-07-06) - original release by Goran Ivankovic
- Lotto generator in VX-REXX: combinations between 1/1 and 99/99, up to 999
  combinations, 5 fixed numbers that appear in every combination, the
  result can be saved to a file, source code included. Freeware
